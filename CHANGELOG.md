# Changelog

All notable changes to **Engine (`stbange/engine`)** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Whenever a release introduces **BREAKING** changes to `include/engine/*.h`, the `eng.*` Lua API, or `schemas/*.schema.json`, see [UPGRADING.md](UPGRADING.md) for automated coding-agent migration instructions.

## [0.2.0] - 2026-11-23

### Added
- **Steerable Walkable Moving Vehicles (`openspec/specs/12-walkable-vehicles/spec.md`, `eng_portal`, `eng_physics`, `eng.space`)**:
  - Moving-portal kinematic tracking (`eng_portal_step_kinematics`, `eng_portal_set_velocity`, `eng.portal.sync_kinematics`) and Galilean relative frame velocity transfer (`eng_portal_transform_velocity`, `eng.portal.transform_vel`, `eng.portal.check_crossing` velocity returns) so exiting a moving/rotating vehicle preserves world momentum and advancing vehicle ramps scoop stationary external entities cleanly.
  - One-call multi-window, multi-station steerable vehicle builder (`eng.space.create_steerable_vehicle`) creating an isolated walkable interior pocket, passable boarding hatch, non-passable panoramic cockpit windshield & side window stencil portals, multi-crew stations, persistent cruise steering, and clamped inertial deck sway (`inertial_sway`, `step_bob_amp`).
  - Default 3-player local split-keyboard action bindings (`p1_*` `WASD+E`, `p2_*` `IJKL+U`, `p3_*` `Arrows+Return`, `switch_crew` `Tab`, `toggle_cam` `C`).
  - **Game `101` (`games/101_giant_cleaner_mech`)**: *Titan Janitor: 3-Crew Cleaning Mech* — three players simultaneously steering, walking, operating Vacuum/Scrubber/Recycler stations, and performing Galilean EVA ramp exits & moving-ramp re-boarding inside a giant 14m bipedal cleaning robot.
  - **Toggleable On-Screen Game Help (`eng_ui_draw_help`, `H` hotkey / Web `Help (H)` button)**: Automatic per-game bottom-left goal description (from `game.json`) and live control hints (from `locales` `"controls"` or runtime-observed input actions) across all 101 games on Desktop and Web.
  - **Materials & Atmospheric FX (`openspec/specs/03-renderer-retro-voxel/spec.md`, `shaders/`, `eng_render`, `eng_particles`, `eng_lua`, `lua/eng/fx.lua`)**:
    - Analytic sky-gradient IBL reflections (`eng_env_ibl`) in Forward and Deferred shaders for gleaming gold, chrome, copper, and wet/metallic materials.
    - Linear HDR `emissive` support (`eng_draw_item_t.emissive`, `set_mesh` `emissive` RGB or scalar) and a back-to-front sorted translucent Fresnel composite pass (`tint.a < 0.99`) working identically in both Forward and Deferred pipelines for glowing crystals, gems, ice, and glass.
    - Built-in 32×32 radial Gaussian soft puff texture (`__soft_puff`), additive blend mode (`additive = true`), full Lua particle controls (`color_start/end`, `size_start/end`, `gravity`, `drag`, `cap`, `eng.particles.set_pos`, `eng.particles.set_rate`), and `lua/eng/fx.lua` (`eng.fx.material` + `eng.fx.spawn` presets for `fire`, `smoke`, `sparks`, `dust`).
    - Updatable dynamic lights (`eng.render.add_light` returning 1-based handle + `eng.render.set_light`) and height-layered colored fog + bloom controls (`fog_color`, `fog_height`, `bloom` in `eng.render.set_retro` and `game.json` `"retro"`), showcased in `099_shader_museum_xr`, `001_catacomb_blitz`, and `049_cursed_lantern`.
  - **Split-Screen Multiplayer, Gamepads & Cross-Platform Networking (`openspec/specs/02,03,05`, `SDL3_net 3.2.0`, `eng_input`, `eng_render`, `eng_audio`, `eng_net`, `eng_lua`, `eng_cli`, `lua/eng/mp.lua`, `server/`, `.agents/skills/engine-server/`)**:
    - 1–4 player local input with SDL3 gamepad hot-plug enumeration (`SDL_INIT_GAMEPAD`) and 4 non-overlapping keyboard zones (`WASD`, `Arrows`, `IJKL`, `TFGH`/`Numpad`) exposed via `eng_input_player_*` and `eng.input.player_*` / `eng.camera.fps_steer_player`.
    - 1–4 viewport split-screen rendering (`eng_renderer_render_views`, `eng.camera.set_split`, `set_view`, `look_at_view`, `get_view_rect`, `eng.ui.viewport_anchor`) across both Forward and Deferred pipelines (with `texelFetch` G-buffer sampling, per-viewport pocket portals/shadows, and crisp divider bars) plus multi-listener 3D spatial audio (`eng_audio_set_listeners`).
    - Cross-platform multi-client networking (up to 16 peers) over RFC 6455 Binary WebSockets (`SDL3_net` on Windows/macOS/Linux + `<emscripten/websocket.h>` on Web so Browser and Desktop clients play together in the same room), multi-client UDP, and multi-client Loopback, plus headless `--server --port <N> --tick-rate <Hz>` dedicated server mode (`scripts/server.lua` or `scripts/main.lua`), `--connect <url>` / `?server=<url>`, `lua/eng/mp.lua`, `--template multiplayer`, `server/{Dockerfile,Caddyfile,docker-compose.yml}`, and `.agents/skills/engine-server/SKILL.md`.
    - Verified native desktop TLS 1.2 (`wss://`) client support via MIT-licensed BearSSL layered over `SDL3_net`, with strict X.509 certificate + SNI hostname verification against OS root CA stores (Windows CryptoAPI `ROOT`, macOS `Security.framework`, Linux `/etc/ssl/certs/...`) and optional PEM CA override (`ENG_TLS_CA_FILE`, `SSL_CERT_FILE`, or `eng_net_set_ca_pem`), so Browser, Windows, macOS, and Linux clients join the exact same `wss://` room invite URL.
    - **Game `102` (`games/102_portal_arena_mp`)** (4P split-screen + cross-play WebSocket arena with Bigger-on-the-Inside crystal vault) and upgraded `101_giant_cleaner_mech` with 3-player split-screen (`V`) and per-player gamepad support.

### Fixed
- **Emscripten WebAssembly & Chrome Player (`CMakeLists.txt`, `src/eng_platform.c`, `src/eng_cli.c`, `web/shell_play.html`)**:
  - Exported `'callMain'` in `EXPORTED_RUNTIME_METHODS`, raised WASM C stack size from Emscripten's 64 KB default to `2 MB` (`-sSTACK_SIZE=2097152`), enabled WebGL2 `EXT_color_buffer_float` for deferred G-buffers, added full-window high-DPI viewport resize + Nuklear HUD label rendering, and added headless Chrome CI smoke gate (`tests/check_web_bundle.py`).
- **Mobile Chrome WebGL2 & Portrait Responsive Layout (`shaders/forward.vert`, `src/eng_render.c`, `src/eng_ui.c`, `src/eng_cli.c`, `web/shell_play.html`)**:
  - Reduced `u_bones` from `64` (`266` vec4) to `48` (`202` vec4) to fit within the GLES 3.0 / WebGL2 `256`-vector vertex uniform minimum on Android mobile GPUs (fixing blank 3D scenes on phones), guarded `pow(0, y)` calls, reset `GL_BLEND` between 3D and UI passes, and added Hor+ portrait FOV compensation.
  - Separated logical CSS UI coordinates from physical HiDPI framebuffer dimensions (`eng_ui_set_fb_size`), fixed narrow portrait HUD & help positioning above bottom touch controls, removed duplicate Nuklear touch widgets on Web, added a `USE` (`interact`) touch button, and converted `web/shell_play.html` to a non-overlapping flex layout so topbar buttons never clip on phones.
- **Relative Mouse Pointer Lock & Camera-Relative WASD Strafing (`eng_platform`, `eng_input`, `eng_lua`, `web/shell_play.html`, Games `001`–`100`)**:
  - Added cross-platform pointer lock (`eng_platform_set_mouse_lock` / `SDL_SetWindowRelativeMouseMode` on Desktop, HTML5 `requestPointerLock()` + `#lock-hint` pill + `ESC` unlock on Web) and Lua helpers (`eng.input.set_mouse_lock`, `eng.input.is_mouse_locked`, `eng.input.mouse_delta`, `eng.camera.fps_steer`).
  - Replaced fixed-target orbiting `look_at` cameras across all first-person, free-roam, walkable-interior, and fixed-center follow games with mouse-locked yaw/pitch look and camera-relative forward/backward/left-strafe/right-strafe movement, and updated the default `fps` scaffold template.
- **WASD + Arrow Dual Bindings, Solid Wall Collision & Floor/Sprite Z-Fighting (`eng_input`, `eng_physics`, `eng_procgen`, `eng_sprite`, `eng_render`, `lua/eng/space.lua`)**:
  - Fixed `eng_input_bind_key` overwriting `WASD` with `Arrow` keys by storing both primary `key` and secondary `alt_key` per action (plus auto-focusing the Web canvas on boot).
  - Added `eng_physics_slide_xz` / `eng.physics.slide_move`, procedural dungeon wall voxel colliders (`voxel_id`, `walkable`, `key_x/key_z`), solid exterior/interior perimeter walls on `eng.space.create_pocket_building`, fixed `eng_nav_set_grid` to replace existing pocket NavGrids across stage transitions, and wired wall blocking + sliding into dungeon and walkable FPS games.
  - Eliminated floor/sprite Z-fighting flicker by offsetting dungeon floor tiles (`+0.01m`), removing redundant coplanar floor meshes in dungeon games (`001`, `014`, `030`, `042`), biasing billboard sprites slightly toward the camera and above `y = 0`, disabling PS1 vertex-snap jitter on sprites, and enabling alpha blending in `draw_pocket_sprites`.
- **Engine Conformity Check Skill & Full 101-Game Audit (`.agents/skills/engine-conformity-check/`, `eng_procgen`, `eng_lua`, `lua/eng/space.lua`, 18 Games)**:
  - Added the reusable `engine-conformity-check` skill (`SKILL.md` + zero-dependency live C-contract scanner `scripts/check_conformity.py`) detecting ignored option keys, unsupported enum fallbacks, unbound input actions, missing wall/prop/pocket collision, Z-fighting, lifecycle leaks, and camera/pocket mismatches.
  - Fixed root engine gaps found by the audit: implemented `wood_grain`, `metal_rivets`, and `lava_cracks` procedural texture recipes in `eng_procgen_texture`, synced physics `pocket_id` inside `eng.scene.set_pocket`, parsed `spread`/`speed`/`life` in `eng.particles.create`, and added solid interior perimeter walls to `eng.space.attach_vehicle_interior`.
  - Applied all 18 per-game conformity propositions (`001` `set_retro` keys; static wall/pillar/prop/interior colliders + `eng.physics.slide_move` across `006`, `007`, `016`, `019`, `020`, `037`, `038`, `043`, `045`, `046`, `047`, `049`, `050`, `055`, `096`, `097`, `098`), achieving 0 errors / 0 warnings under `--strict`.
